# 行为面标注规范（草案 v0.1）

> ⚠️ **本文件是工程侧起草的草案，最终口径由新闻学队友定稿。**
> 定稿后请把版本号写进文件名（`annotation_guide_v1.md`），不要覆盖本文件。

## 1. 标注对象

`data/labeled/*.jsonl` 的每一行是一篇公众号文章（或一段短视频转写）。每篇需要标：

| 字段 | 取值 | 说明 |
|---|---|---|
| `cognitive_label` | 真 / 假 / 部分属实 / 无法核查 | 认知面：文章整体的事实性判定 |
| `behaviors` | 见第 2 节，可多选，可为空 | 行为面：命中的行为类型 |
| `topic` | 慢病 / 用药 / 饮食 / 癌症 / 养生器械 / 其他 | 用于分层划分 dev/test |

`behavior_level` 不用人工标，由 `behaviors` 按规则自动推导（见第 3 节）。

## 2. 行为类型定义

| 类型 | 判据 | 正例 | 反例 |
|---|---|---|---|
| 转发诱导 | 以道德绑架、利益诱导或恐吓要求转发 | "转给家里老人""不转不是中国人""功德无量请转发" | "欢迎分享给需要的朋友"（无绑架意味，不标） |
| 医疗行为建议 | 建议停药、换药、改剂量，或用偏方/保健品替代正规治疗 | "吃了这个就不用吃降压药了""把药停掉改喝这个" | "遵医嘱调整用药"（不标） |
| 消费导流 | 推荐购买保健品、器械、理疗服务，附购买链接、二维码或联系方式 | "点击下方链接购买""加微信领取体验装" | 科普文中提及某类产品但不带货（不标） |
| 金钱相关 | 要求付费、转账、加入会员或参与理财 | "交199元入会""转账到指定账户""投资稳赚" | 文章本身在讨论费用政策（不标） |
| 恐惧诉求 | 夸大危害、制造紧迫感，用恐惧推动行动 | "再不看就晚了""已经死了好多人""医生都不敢告诉你" | 客观陈述疾病风险（不标） |

**边界处理原则**：
1. **看话术，不看事实**。行为面只看文章怎么说话，不管内容真假——真假交给认知面。一篇内容真实的文章也可以有恐惧诉求。
2. **必须能摘出原文片段**。标一条行为就要能指出原文哪句话，摘不出就别标。
3. **营销话术与科普表述分开**。"吸烟会增加肺癌风险"是客观陈述；"再抽烟你就等死吧"是恐惧诉求。
4. **一条可同时命中多类**。如"加微信买这个，不用吃降压药了"同时命中 `消费导流` 与 `医疗行为建议`。

## 3. 风险等级推导规则

不用人工标，代码按 `config.yaml` 的 `behavior.risk_rules` 推导，顺序匹配、先命中先返回：

| 等级 | 条件 |
|---|---|
| 高 | 命中 `医疗行为建议` 或 `金钱相关` |
| 中 | 命中两类及以上其他类型 |
| 低 | 命中一类其他类型 |
| 低 | 未命中任何类型 |

**注意顺序敏感**：同时命中 `医疗行为建议` 与 `转发诱导`，结果是**高**（第一条规则先命中），不是中。

## 4. 标注流程

1. **抽样**：从 `data/raw/` 按 `topic` 分层抽样，保证各 topic 都有。
2. **独立标注**：两名队员**各自独立**标注全部样本，标完再比对，中途不讨论。
3. **双标抽检**：随机抽 20% 计算 Cohen's Kappa。**Kappa < 0.6 需回炉讨论口径**，修订本规范后重新标。
4. **分歧处理**：讨论后仍不一致的，记为第三类"存疑"，在 `notes` 里写明分歧点。**不要为了凑一致率而强行统一。**
5. **冻结**：`test.jsonl` 一经定稿即冻结，**禁止用于调提示词、阈值或规则**（`eval.py` 在跑 test 时会打印警告）。

## 5. 实测发现的边界案例（M3 产出，**必须定稿**）

M3 用真实模型在 12 条合成样本上跑了一遍行为面，**五个类型 recall 全部 1.000（一条没漏），
但 precision 只有 0.5~0.8**。误报全部集中在这三处边界上——**这不是模型的毛病，
是标注口径没说清**。请重点裁定：

### 5.1 `医疗行为建议` vs `消费导流`

**案例**："多吃碱性食物如海带、西兰花，可以调节身体酸碱平衡，把癌细胞饿死。"
- 模型判：`医疗行为建议`（饮食替代治疗的表述）
- 金标准判：`消费导流`

**问题**：这句话**没有购买引导**，按第 2 节定义不该是 `消费导流`；但它确实是
"用饮食替代正规治疗"，符合 `医疗行为建议`。**倾向认为金标准标错了。**
请裁定：**没有购买链接、但明确推荐某种饮食/偏方替代治疗的，标 `医疗行为建议`。**

### 5.2 `恐惧诉求` 是否包括"错误论断"

**案例**："人体体质偏酸容易生病，癌症患者都是酸性体质。"
- 模型判：`恐惧诉求`（+1 次误报）
- 金标准判：不标

**问题**：这句话是**错误论断**（伪科学），但**不是在制造恐惧推动行动**。
第 2 节的反例里只写了"客观陈述疾病风险不算"，**没写"错误论断算不算"**。
请裁定：**单纯陈述一个错误结论，不标 `恐惧诉求`**（它该由认知面判为"假"）。
`恐惧诉求` 必须含有"夸大/紧迫/恐吓"的话术成分。

### 5.3 `金钱相关` vs `消费导流`

**案例**："现在加入会员还能享受一对一指导，年费只要1999。""原价998今天99。"
- 模型判：`金钱相关`（+1 次误报）
- 金标准判：`消费导流`

**问题**：两者都是"要钱"，区别在哪？建议按**目的**分：
- `消费导流`：**卖实物/服务**（保健品、器械、理疗、课程），有商品或服务标的
- `金钱相关`：**收钱本身**（入会费、转账、投资、理财），标的不是商品

请按这个口径裁定，并补进第 2 节的判据栏。

### 5.4 需要补进第 2 节的反例

| 类型 | 建议补充的反例 |
|---|---|
| 恐惧诉求 | 错误论断（"酸性体质"）——不标；客观风险陈述——不标 |
| 金钱相关 | 卖实物/服务的会员费——应标 `消费导流` 而非本类 |
| 消费导流 | 无购买引导的饮食/偏方推荐——应标 `医疗行为建议` 而非本类 |

> **为什么这些必须在标注前定下来**：M3 的误报率（precision 0.5~0.8）主要由口径不清导致。
> 如果 300 条标注按现在这套模糊口径做，Kappa 大概率过不了 0.6，回炉成本远高于现在先吵清楚。

### 5.5 真伪口径：省略限定条件算「部分属实」（2026-10-12 用户裁定，D55）

**定义**：文章或说法的主体方向有依据，但核心健康说法**省略了权威来源要求的限定条件**——
适用人群、剂量 / 频次、前提条件，或「辅助 / 有助于 / 可能」这类程度限定——以绝对化、普遍化或必然化的形式表述，
标 `部分属实`。

| 情况 | 标注 | 例子 |
|---|---|---|
| 疗效说法去掉了「辅助」，或扩大了适用范围 | 部分属实 | 「刮痧对高热、类风湿关节炎……有很好的疗效」 |
| 把可能性、关联说成必然或确定的因果 | 部分属实 | 「每天一瓶无糖饮料，三到五年后就会有内分泌问题」 |
| 省略了「仅限某些剂型 / 人群」 | 部分属实 | 「发芽土豆挖掉芽、泡水加醋就可以避免中毒」 |
| **只有标题**夸大，正文明确补回了限定 | 真 | 标题「能降血脂、控血压」，正文写「辅助调节」 |
| 主体正确，只有个别数字笔误 | 真 | 把中风溶栓窗口 4.5 小时误写到心梗上 |
| 核心说法本身与权威结论相反 | 假 | 不属于本条 |

判断时**不看系统的预测结果**；改标须摘出原文依据，并写明省略了什么限定。
